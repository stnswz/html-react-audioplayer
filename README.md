Example application for a html audio player. The application is implemented in React JS / TypeScript, uses Hooks, Redux, Redux-Thunk and is fully responsive. You can see the player in action on [react-audioplayer.netlify.app](https://react-audioplayer.netlify.app).

Based on this html audio player, I also created a simple example html video player, you can find here: [react-videoplayer.netlify.app](https://react-videoplayer.netlify.app).
